# B04 — 比例排版与可编辑 DXF 引擎

执行前阅读 plan、contracts C02/C05、requirements R03/R04、B02格式/模板决定、B03报告和progress。

## 1. 目标与明确的不做事项

把已校验数据与已确认比例变成确定的DrawingPage和原生汇总DXF；整批预检超框/碰撞/字形，提出可解释比例推荐。不做电阻设计、三维、通用在线CAD，不擅自改参数、不假定预览图等于可编辑交付。

## 2. 前置依赖

B02核心门槛、B03 passed；若B02将DWG升级为必需则其新增门槛也通过。模板坐标/字体/引线参数不得仍是待猜值；先检查批准hash与当前文件匹配。

## 3. 预计修改的模块和文件

- 扩展B02已有 `drawing/{template,profile,dxf_writer,readback}.py`；新增 `drawing/{geometry,layout,scale,collision}.py`。
- `service/src/heater_drawing/domain/models.py` 的 DrawingPage实现；`templates/heater-a4-v1/`仅在批准变更时更新版本/hash。
- `scripts/{draw_case,check_drawing}.py`，`fixtures/layout/*.json`。
- `tests/drawing/{test_geometry,test_layout,test_scale,test_dxf_readback}.py`；registry、B04报告/evidence/progress。

## 4. 接口、数据结构和兼容性约束

`plan_pages(revision, template)`返回pages/issues/proposals，不改变revision。不接受未确认推荐比例的正式导出；纯布局试算可生成明确标记的诊断数据，不注册成Artifact。

真实geometry_mm固定，纸面缩放遵从B02 profile；矩形闭合无圆角、短上长左、正方形上。引线线距/插入/示意长度使用受控参数；小尺寸不足以容纳引线时给明确row错误，不让引线相交后照常出图。

按R04执行比例候选、完整包围盒与避让；标注可优先底部/右侧，受长边引线/大尺寸影响时从受控候选位选择，无可用位置则报错。不得压缩字高到未知可读性阈值以下、覆盖模板栏或只判断矩形放得下。尺寸用原生DIMENSION、DIMLFAC=1，回读真实测量；TEXT/MTEXT可编辑，不能用线段拼出所有文字来绕开字体问题。

汇总DXF modelspace按输入顺序tile排列；每行独立A4 layout，row_id/code映射写清单。图层建议 `HEATER_OUTLINE/HEATER_LEADS/HEATER_DIMS/TITLE_TEXT/FRAME`，保持模板已有必要图层；颜色/线宽由profile定。保留空白非输入字段，不增加签名/日期。

## 5. 可执行的验收步骤与通过条件

1. `.venv/bin/python scripts/draw_case.py --input fixtures/case/加热器图纸.xlsx --template templates/heater-a4-v1 --output docs/evidence/B04/case`：默认只对无错误且无需比例变更的真实三行生成；案例输出1:1、1:1、1:2，生成单一汇总DXF和page映射。
2. `.venv/bin/python scripts/check_drawing.py --dxf docs/evidence/B04/case/加热器图纸.dxf --expected fixtures/case/expected.json --pages docs/evidence/B04/case/pages.json --output docs/evidence/B04/readback.json`：独立读回真实坐标、尺寸实体/测量、图层、文字、layout和单位；轮廓与尺寸误差≤1e-6 mm，100×300没有变成50×150模型实体。
3. `.venv/bin/python -m pytest -q tests/drawing`：三种出线/正方形、保持合法输入比例、刚好放得下与稍超框、推荐1:2/1:5、候选无解、长文字溢出、缺字、引线/标注碰撞、边界字体宽度、不同scale不改变真实尺寸。未接受proposal不得生成正式DXF。
4. 对同一规范输入重复排版，比较语义结果/顺序/比例；字节不同若来自合法元数据需解释，不依赖截图像素证明工程精度。
5. `.venv/bin/python scripts/verify_batch.py B04 --report-dir docs/evidence/B04`；保留三个样例渲染供人工追踪，但本批不以“看起来像”代替实体检查。

通过：真实三行可编辑图元和字段准确；比例推荐不自动生效；所有排版错误能在绘制前标记对应行；现有B02模板批准未失效或已重新取得。

## 6. 需要人工决定的事项

新字体、改变图框/工艺文字、引线画法、建议比例序列或无法满足可读性的取舍需要带样图决定。普通尺寸避让在既定规则内由实现者完成，无需逐张询问。用户确认比例是未来运行时操作，不是本批开发者替用户批量批准。
