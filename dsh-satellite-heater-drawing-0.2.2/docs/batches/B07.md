## 4. 接口、数据结构和兼容性约束

规划身份：npm包 `@qmh/dsh-satellite-heater-drawing`，Cordis/工作区id `custom-heater-drawing`，workspace key `heater-drawing`，MCP server `satellite-heater-drawing`，工具前缀 `heater_`。B07先检测宿主冲突和私有安装规则，若需改命名一次性更新所有入口和测试。

Host保管service base URL/令牌，注入可信owner/session；浏览器只访问DSH同源代理。使用installAnchor解析宿主模块避免dsh-tools双实例；保留metadata/label兼容，不发布另一份Host单例依赖。build须校验所需产物缺失硬失败（B07自身壳、B08完整web）；插件包不包含venv、输入图纸、客户数据、ODA或未许可字体。

最小MCP工具：`heater_capabilities`、`heater_job_status`、`heater_explain_issues`、`heater_open_workspace`，在可信附件机制经过验证后可增加`heater_import_attachment`（只接受宿主附件ID，禁止任意文件path/URL）。start/cancel/retry若通过对话提供必须复用服务端状态约束。scale/skip/review只有真实用户确认入口签发receipt，普通LLM工具不能签发。若宿主无法可信区分交互事件，首版让用户在工作台确认，不牺牲门槛。

Host确认端点采用认证同源请求、CSRF防护/Origin约束，校验当前用户会话与页面展示revision；receipt一次性、短有效期、绑定具体集合，服务端使用Host共享密钥验证签名且不会被转发给MCP任意调用者。密钥与服务令牌分开配置，不能放进JS bundle。B06测试issuer生产路径禁用。

## 5. 可执行的验收步骤与通过条件

1. `npm ci --prefix plugin`、`npm test --prefix plugin`：identity一致、工具参数严格、非法会话/附件拒绝、Host token不进浏览器、CSRF/receipt重放/伪confirmed不成立。
2. `npm run build --prefix plugin`、`npm pack --prefix plugin --pack-destination work/packages`；`node scripts/check_plugin_package.mjs --package-dir plugin --output docs/evidence/B07/package.json`。package checker检查实际pack清单，不只package.json files字段；记录tarball hash。
3. 在隔离DSH测试profile加载插件，工作区唯一显示“矩形加热器出图”；Host侧读取capabilities、某测试job；切换会话不可见原任务，MCP无法构造另一owner/session。
4. 设置错误服务地址/令牌，UI壳与工具都能解释不可连接/未授权；日志不输出凭据；宿主卸载/重载不遗留重复注册或MCP进程。
5. 实测浏览器网络仅DSH同源，原服务令牌/确认密钥不存在于bundle、localStorage或网络响应；用真实测试Host确认一次scale/skip再重放应409。
6. `.venv/bin/python scripts/verify_batch.py B07 --report-dir docs/evidence/B07`，归档宿主版本、注册证据、协议样例和测试账户范围。缺可用测试宿主则该项blocked，不能以mock通过整体。

通过：实际测试Host可加载、API可用、身份与确认边界正确，包可复现。完整上传/出图UI尚在B08，不在本批宣称完成。
