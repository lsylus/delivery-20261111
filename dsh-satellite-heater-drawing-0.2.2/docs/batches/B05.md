# B05 — A4 PDF、最终 Excel 与完整交付包

执行前阅读 plan、contracts C05、requirements R02/R06、B02与B04报告、progress。

## 1. 目标与明确的不做事项

从已回读通过的DXF生成每行A4 PDF，准确合并；构造与冻结集合一致的DXF/PDF/Excel/报告/manifest/ZIP。此批提供文件级构建和核验，不实现HTTP、身份、任务队列或人工审核界面；不默认发布部分结果。

## 2. 前置依赖

B04 passed，B02 renderer/font profile固定。导出函数输入必须是已冻结revision+expected_row_ids，不允许临时从目录里glob全部PDF来推定交付集合。

## 3. 预计修改的模块和文件

- 扩展 `drawing/pdf_renderer.py`；新增 `delivery/{pdf_merge,workbooks,manifest,package,validation}.py`。
- 扩展 `excel/actual_workbook.py`；`schemas/artifact.schema.json`。
- `scripts/{build_delivery,check_delivery}.py`，`tests/delivery/{test_case,test_completeness,test_workbooks,test_failures}.py`。
- `fixtures/delivery/`包含scale已确认/skip已确认的冻结revision夹具，仅测试用，明确不是生产批准。
- registry、B05报告/evidence/progress。

## 4. 接口、数据结构和兼容性约束

按C05同源渲染、单页验证后合并；纵向210×297 mm。单页按code命名，合并按expected_row_ids的原行顺序。名称安全由B03和服务边界共同校验，不能拼接原输入路径。

original.xlsx保留上传字节；actual.xlsx Sheet1仅最终交付行/最终比例，变更记录sheet含原row_id、原/最终比例、跳过原因、确认者/时间及revision；输入未提供的工程字段不能生成。row-report包含每行状态、输入值、最终值和错误/跳过详情，PDF不要加未经批准的工程图封面改变页数。跳过提示出现在结果页面/报告，merged PDF页数只等于交付行数。

manifest文件hash不自引用；zip包括manifest，外层run记录zip/manifest hash。原件Excel包含被跳过行不是漏筛选：原件用于追溯，actual与图纸集合必须精确一致。如果DWG已纳入profile，则调用B02 adapter生成汇总DWG并验证，同样纳入文件集；未启用则manifest明确format未提供，不出现空DWG占位。

## 5. 可执行的验收步骤与通过条件

1. `.venv/bin/python scripts/build_delivery.py --revision fixtures/delivery/case-revision.json --dxf docs/evidence/B04/case/加热器图纸.dxf --pages docs/evidence/B04/case/pages.json --output docs/evidence/B05/case`。若B04 evidence在另一机器，先按hash恢复其输入并重跑，不使用同名未知文件。
2. `.venv/bin/python scripts/check_delivery.py --directory docs/evidence/B05/case --expected fixtures/delivery/case-revision.json --output docs/evidence/B05/check.json`：3张单页、合并3页、顺序正确，A4误差≤0.2mm，DXF/实际Excel/报告/manifest都是同3条，原Excel hash不变。
3. 渲染每个单页及合并对应页，核对图面/颜色/字段；自动图像比较辅助发现裁切和错页，人工看中文/Ω/±/备份数量和尺寸。已有参考PDF O3错字需豁免为已知差异，其余差异逐项解释。不能只数PDF页数或提取文本。
4. `.venv/bin/python -m pytest -q tests/delivery`：缺页、重复页、错顺序、单页PDF实际2页、损坏PDF、错误hash、额外残留页、路径逃逸、文件重名、超长quantity、scale覆盖追溯；注入第2行失败不得产生可正式发布的完整包。
5. 明确跳过第3行夹具：只有2个单页、合并2页，actual Sheet1为行2/4；原Excel仍3行，报告清楚标skip。未给skip决定时同一缺行必须失败；全部skip必须失败。
6. `.venv/bin/python scripts/verify_batch.py B05 --report-dir docs/evidence/B05`。

通过：所有对应关系与hash一致，错误不会产生伪“成功包”，视觉渲染无裁切/缺字，用户能够从包重建本次实际出图参数。

## 6. 需要人工决定的事项

采用既定单页、合并、原始/最终Excel等交付物无需重新确认。新增封面、额外页码、改图框、PDF黑白化或移除追溯文件应先给样件说明影响并确认，不能以美化为由更改。
