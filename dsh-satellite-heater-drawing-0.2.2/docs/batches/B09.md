# B09 — 真实案例端到端与工程验收

执行前阅读完整plan/requirements/contracts、B02格式决定、B08报告、progress。

## 1. 目标与明确的不做事项

在测试部署中证明真实工程数据、CAD图元、PDF图面、用户确认与交付清单全部一致，并让命名工程审阅人检查可编辑性及交付标准。只修复此范围缺陷，不新增功能、不部署生产，不把其他项目转换证据转记为本项目验收。

## 2. 前置依赖

B08 passed（其依赖链均有效）；实际构建包、服务代码、模板/字体/profile固定。准备适用目标CAD环境和工程审阅人；如果没有，可先完成自动项但整体blocked。

## 3. 预计修改的模块和文件

- `scripts/acceptance_engineering.py`、`fixtures/acceptance/`、`tests/acceptance/{test_full_case,test_failure_matrix,test_isolation}.py`。
- `docs/acceptance/{checklist,known-differences}.md`、`docs/evidence/B09/`、`docs/reports/B09.md`、progress、registry。
- 缺陷修复只在已有模块，报告写明影响Batch并重跑对应门槛；不修改既有测试把真实失败变成豁免。

## 4. 接口、数据结构和兼容性约束

按C07绑定源码/包/模板/字体/输入/输出hash，工程审阅绑定同一组文件。软件验收报告不得虚构签名、复核通过或加工公差。已知差异只有经登记的Excel O3权威修正、允许的规范化排版和已批准字体替代等，不能用宽泛“视觉差异正常”排除失败。

本项目三条真实案例为主；另建立错字段、超框、长文字、同代号、运行失败、重启/取消的受控副本。没有真实工具运行的项目明确not_run。DWG disabled时不把缺DWG算DXF发布失败，但必须在限制中醒目标明；enabled时DWG是必验且失败阻止通过。

## 5. 可执行的验收步骤与通过条件

1. `.venv/bin/python scripts/acceptance_engineering.py --profile tests/acceptance/test-environment.json --output docs/evidence/B09`：通过真实Host→服务→worker生成三行；调用B04回读/B05交付核验；不直接绕过服务调用引擎当端到端。
2. `.venv/bin/python -m pytest -q tests/acceptance`；用已构建包复跑 `npx playwright test --config playwright.config.ts` 中核心流程，区分真实外部依赖与注入故障。
3. 工程逐图验收：25×25上出线/1:1；30×50左出线/1:1；100×300上出线/1:2。核对17字段、8条技术要求、数量原文、标审郑玲、黄色框、无越框/重叠/缺字；PDF实际纸面几何符合缩放，轮廓真实模型毫米尺寸正确。
4. 目标CAD（默认AutoCAD 2018）对本批汇总DXF打开、检查3个layout/实体、修改轮廓/文字/尺寸、保存重开；记录输入和编辑后hash、CAD版本、编辑对象及结果，确认不是图片或不可编辑代理。若启用DWG，对确切DWG同样执行。替代CAD必须在format决定中明确接受，不能用FreeCAD/ODA回读替代AutoCAD名义验收。
5. 失败矩阵：上传错误先不绘图；scale待确认不排队；明确skip后只有预期2页且报告可见；运行中错行不发布半包；旧确认拒绝；全skip拒绝；两个会话无交叉预览/下载；断网/刷新/worker重启后状态与产物一致。
6. 工程审阅人填写 `docs/evidence/B09/engineering-review.json`（姓名、时间、范围、各hash、发现、approved/rejected）。不把案例Excel上的设计/批准人员自动写为本系统审阅人。
7. `.venv/bin/python scripts/verify_batch.py B09 --report-dir docs/evidence/B09`：必需自动项和人工项均通过。缺CAD环境/工程签收时exit2，不先标passed等以后补。

通过：全部预期图纸可编辑、正确且可追溯；合并包没有静默漏图；异常和隔离路径可信。不能只凭用例数量、截图或HTTP200签收。

## 6. 需要人工决定的事项

工程审阅人决定样图是否满足正式工程交付标准，需提供可审查实际包和具体差异。是否将DWG纳入首版依据B02决定；若此时变更范围，回到B02补验证并更新后续契约，不临时以“另存即可”替代自动DWG要求。

## 7. 交接

冻结可发布候选代码/包/template/profile，记录所有hash、已知限制和无待修阻断缺陷。B10只部署该候选；若期间修复代码、模板或格式路径，重跑受影响验收与人工门槛。
