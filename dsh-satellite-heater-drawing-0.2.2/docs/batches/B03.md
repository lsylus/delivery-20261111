# B03 — Excel 导入与整批校验

执行前阅读 plan、contracts C01/C02、requirements R01/R02/R05、progress 和 B01 报告。

## 1. 目标与明确的不做事项

把上传Excel解析成带原行号的17字段记录和可操作错误清单；完整保留原值及数量文字。此批不绘图、不做比例是否超框的几何判定、不调用CAD、不跳过错误行、不实现网页编辑/回写UI。

## 4. 接口、数据结构和兼容性约束

实现 `parse_workbook(path, limits)` 和 `validate_rows(rows, template=None)` 中不依赖图面的部分。沿用R01的表头映射/Sheet1/空行/公式约束。解析失败要给 workbook issue；具体字段错误给 source row/field/原值/原因/修正建议。文本不执行，数量保持原文；code同时检查跨平台文件安全与大小写重复。

全部非空业务行都记录：错误行不能被dataframe类型转换或dropna吞掉；尾部仅格式空行/空R列忽略。遇重复代号，给所有相关行同组错误，供后续确认保留哪一行，不能保留第一条后自动丢弃第二条。格式化但无真实值的行不算记录；部分填写必须报必填错。

本批校验比例格式与范围（1:n，n>0且n≥1），不决定可放下。解析设计人员等文字时不能默默用数值0代替空值。禁止执行或取公式缓存；导出文字单元格强制字符串，以防公式注入。限制zip entries/解压总量，拒绝损坏或伪装xlsx；仅校验已支持内容，不导入外链。

## 5. 可执行的验收步骤与通过条件

1. `.venv/bin/python scripts/check_excel.py --input fixtures/case/加热器图纸.xlsx --output docs/evidence/B03/case.json`：exit0，只有行2/3/4，17字段与expected.json一致，O3=郑玲，数量三段原文精确保留。
2. `.venv/bin/python -m pytest -q tests/excel`：至少覆盖缺/重复表头、换序列名、全空格式行、半空记录、公式、合并单元格、多表提示、空字符串、布尔/NaN/Inf、宽>长、零/负值、非法出线、零/负偏差、非法比例、重复代号、保留名/路径穿越、超限/压缩炸弹模拟、公式式文字导出安全。
3. 对错误夹具调用check_excel，exit1且结构化错误包含准确sheet/row/code/field/fix；表级损坏不能给可跳过row。所有错误行仍在报告，无输出CAD/PDF。
4. 回写测试验证只有用户原文/规范数值，没有添加业务字段或重算数量；原文件hash不变。缺字/文字溢出尚未测试须明确待B04，不伪报全图可画。
5. `.venv/bin/python scripts/verify_batch.py B03 --report-dir docs/evidence/B03`。

通过：真实3行与负向夹具均符合契约，错误可定位、无静默数据修复，输入限制可配置并有文档。脚本收到无效业务Excel返回失败与完整结果，不进绘制。

## 6. 需要人工决定的事项

R01中的输入约束是明确实施默认值。若实际新增表格要求多工作表、缺少签署字段、公式计算或放大比例，先给差异与影响后再决定；不为了兼容未知表格取消必填/静默猜字段。无需再次确认已定的Excel权威性和宽≤长。
