## 4. 接口、数据结构和兼容性约束

实施 C05最小导出/回读/渲染与C06 adapter。默认 output_profile=`dxf_pdf_v1`、DXF R2018、INSUNITS=4（mm）。早期 DrawingPage 使用 C02，不自创后续无法消费的样例结构。

模板准备两条可选路线：有适用许可时由原DWG转DXF并核验；否则从有尺寸依据的模板/图面重建可编辑矢量框并人工审定。后者须记录不能原生测量的参数与证据，不能用截图嵌入DXF假装复刻。模板需完整层、线宽、颜色、字段锚点/包围盒、禁入区、文字样式、固定段落、引线参数、有效绘图区、标准比例列表、hash和版本。

按 R04 先检验“真实1:1模型＋按分母放大纸框/文字＋每行viewport＋PDF同源裁切”。每种比例回读轮廓和DIMENSION，不得只检查画面标注数字。B02发现选型不支持时须在此修改契约和小样，不能让B04继续踩未决问题。

字体策略要实际检查所有中文、Ω、±、全角符号覆盖。SHX原样、转换矢量或批准TTF替代均须证据；CAD文字仍须可编辑。输出PDF允许文字转矢量，但需另保存字段到图元的校验映射；不依赖PDF可搜索性证明文本正确。

DWG adapter 默认 disabled；真实验证需要独立临时输入/输出、记录转换器与字体hash、target=ACAD2018，回转DXF检查实体、单位、图层、尺寸和中文。返回 `verified_evaluation_only` 不自动改 production_ready。不将ODA二进制/未经许可字体加入Git或包。

## 5. 可执行的验收步骤与通过条件

1. 读取/准备模板，输出模板对象清单和坐标测量表，列出来源、单位和原始/受控模板hash。图框和技术文字逐项比对，O3差异明确按Excel。
2. `.venv/bin/python scripts/probe_formats.py --fixture fixtures/synthetic/heater_sample.json --profile dxf_pdf_v1 --output docs/evidence/B02/dxf-pdf`：真实生成3页DXF/PDF，回读必须是闭合矩形、双引线、可编辑TEXT/MTEXT和DIMENSION；25/30/50/100/300的几何及测量正确，A4/黄色框/字体完整。
3. 在已确认有适用评估条件后运行 `.venv/bin/python scripts/probe_formats.py --fixture fixtures/synthetic/heater_sample.json --profile dwg_candidate --output docs/evidence/B02/dwg`。若不具备许可/工具条件，保存明确blocked，**不运行**转换、不把测试跳过当pass。具备条件则必须真实正反转，保存argv/exit/log/hash与语义比较。
4. 开发阶段在5090宿主机已装FreeCAD 0.19.2打开精确DXF副本，实际编辑轮廓、文字，验证尺寸对象/自动与显式更新，分别保存FCStd和DXF、关闭重开。保留输入/输出/hash/操作记录；GUI崩溃、字体丢失、尺寸丢失、单位/布局变化必须如实列限制。截图和FCStd成功均不能替代DXF往返验收。AutoCAD 2018兼容性未验证，正式具名检查留交付前。
5. `.venv/bin/python -m pytest -q tests/formats/test_probe_failures.py`：工具缺失、超时、转换exit0却无有效文件、缺字、非法模板、单位漂移、原生尺寸丢失均可识别；mock仅验证错误处理。
6. `.venv/bin/python scripts/check_format_gate.py --decision docs/decisions/format-profile.md --evidence docs/evidence/B02-development-baseline --stage development`；再运行统一 `verify_batch.py B02`。格式决定须有机器可核查配套JSON（由本批定义），不能只解析自由文字猜批准。

开发必需项：精确DXF/PDF样件、实际引线矩阵、FreeCAD实际操作及限制记录、DWG延期决定、当前源码B01依赖及必要回归。FreeCAD兼容失败独立标记，不得改写成兼容通过；本轮开发完成不以待指定工程人员阻塞。加工交付必须执行delivery阶段具名工程审批，AutoCAD保持未验证直到真实验证。B02实现者不得自行充当独立审查；当前执行者不自行启动后批；独立技术验收通过且依赖满足后由调度继续。
