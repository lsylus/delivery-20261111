# 0.2.2 发布说明

0.2.2 在当前 DSH 原生右侧栏中显示工作台；0.2.1 在浏览器新标签页打开。
0.2.0 是最初的完整包。三个版本均可作为完整安装包，不要求按顺序安装。

| 版本 | 功能 | SHA256 |
| --- | --- | --- |
| 0.2.0 | 出图后端和原工作区入口 | 7a8c6ea2a839dbdbc1c2a77ba275a0e98c7b9fae288cc9b31cdc547ff869f8d1 |
| 0.2.1 | 会话标题按钮，打开新网页 | ed4df1504dfee18e92814036fe19296597ce4ae682920457cf7db1b671b9be51 |
| 0.2.2 | 会话标题按钮和原生右侧栏页面 | 6999f02aaf6ae5cb98a8163ae5786b613d21dcac13c0b5c1b314bd6f190efbe9 |

0.2.2 相对 0.2.1 的包内容仅变化 package.json、README.md、src/client.jsx、
lib/client.js。81 个运行清单文件一致，后台能力仍报告出图引擎 0.2.0。

侧栏检查通过：类型和内容注册、无 agent-page 的入口、重复打开复用、折叠后
保留、切换会话隔离及恢复、关闭重开、特殊字符编码、420px 宽度、无新标签页、
无会话禁用及无浏览器脚本异常。详细记录保留在本地 `docs/evidence/sidebar-022/`。

现场限制：9999 在 2026-11-11 的部署变化后安装异常尚未解决；本版本没有
真实登录 DSH 页面安装验收结果。原生 CAD 引擎开发验收、Host 模拟测试与
真实部署验收分开记录。没有 AutoCAD 复开或正式工程审批的通过声明。

GitHub Release 建议附上 0.2.2 tgz 和 SHA256SUMS.txt，并保留上述安装限制。
