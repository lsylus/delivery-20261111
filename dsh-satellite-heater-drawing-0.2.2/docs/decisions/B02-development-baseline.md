# B02 开发基线决定

来源：本执行聊天中用户的五项决定及随后调度转发；这是开发方向确认，不是加工交付批准。记录日2026-11-09（Asia/Shanghai）。

- 接受fix-12整体和当前PDF字体；技术要求纸面右移3mm、上移8mm，预览三页。原始材料、fix-12候选和历史报告保留。
- 令S=min(宽,长)/比例分母，所有结果为纸面mm。线距=min(12,max(2,0.25S),0.60S)；内伸=min(10,max(2,0.20S),0.35S)；外伸=min(12,max(3,0.25S))。短边保护优先于名义下限。三页分别为6.25/5/6.25、7.5/6/7.5、12/10/12；第三页比例1:2，实体长度相应乘2。
- 实际导线长度300mm技术文字保持；上述为示意。短边出线上方，长边左侧，正方形上方。规则不依代号、同一纸面尺寸不依模型尺寸/比例；完整图元须在有效绘图区且避开固定文字，并与尺寸实际线段/箭头/字形留≥0.25mm间隙，不满足即拒绝，不能默认放行或自动换比例。
- 使用5090宿主已装FreeCAD 0.19.2，无Docker、不安装替代CAD。原生GUI导入崩溃与命令行原生导入结果分别记录，FCStd与DXF分别测试，不将前者称作DXF往返成功。
- 开发gate与delivery gate分开。正式具名工程审批保持pending、AutoCAD未验证、DWG首发延期；这些不阻塞本轮开发调查，且不授予加工批准。
- 实现完成后由调度安排独立审查，独立技术验收通过且满足依赖后可继续后批；当前执行者不自行启动后批或其它聊天。
