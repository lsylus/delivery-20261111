# 需求、输入与图纸基线

B02本轮增补（R03/R04/R07，2026-11-09）：fix-12及PDF字体接受为开发外观基线；技术要求纸面右3/上8mm。引线按短边纸面长度确定，保留300mm实际导线技术要求。先测宿主FreeCAD 0.19.2，输出可编辑性及保存格式限制，AutoCAD明确未验证。正式具名工程批准在加工交付前完成，开发技术工作不以未指定人员为阻塞；当前执行者仅完成B02；最新用户授权允许调度在B02独立技术验收通过且满足后批依赖后继续推进，确实阻断必要依赖且无法解决时停相应批。
2026-11-07。本文是实现依据；原始材料、历史版本位置和服务器核查见 [project-baseline.md](project-baseline.md)。确定需求优先于原案例旧运行环境和历史建议。

## R01：输入与字段

首版建议约束：只接收 `.xlsx`；指定 `Sheet1`，首行为表头；按已知表头映射而非盲信列位置。表头仅规范化换行、两侧空格、全半角括号；不做模糊匹配。列顺序可变；重复/缺失/未知非空业务列报表级错误。忽略全空列及仅带格式的空行；有任意字段值的行必须完整校验。仅处理 Sheet1，不悄悄选择其他工作表；其他非空工作表提示未处理。公式、宏、外链及合并业务单元格不作为受支持输入，不执行公式、不采用未知新鲜度的缓存值。B03 将这些约束显示在导入说明。

| 列 | 原表头（去换行展示） | JSON 字段 | 类型/规则 |
|---|---|---|---|
| A | 加热器名称 | name | 非空文字 |
| B | 加热器代号 | code | 非空、批内唯一、可安全作为文件名 |
| C | 加热器宽度（mm) | width_mm | 正有限数，≤length_mm |
| D | 加热器长度(mm) | length_mm | 正有限数 |
| E | 出线方向 | lead_side | `短边`→short / `长边`→long |
| F | 阻值(Ω) | resistance_ohm | 正有限数 |
| G | 阻值偏差(Ω) | tolerance_ohm | 非负有限数；不能大于阻值（基础一致性规则） |
| H | 投产数量 | quantity_text | 非空原文，不解释备份、不加减 |
| I | 绘图比例 | requested_scale | `1:n`，n 为正有限数；不支持放大比例 |
| J | 单位名称 | organization | 非空文字 |
| K | 型号名称 | model | 非空文字 |
| L | 设计人员 | designer | 非空文字 |
| M | 校对人员 | checker | 非空文字 |
| N | 审核人员 | reviewer | 非空文字 |
| O | 标审人员 | standards_reviewer | 非空文字 |
| P | 批准人员 | approver | 非空文字 |
| Q | 阶段标记 | stage | 非空文字 |

17 项均按必填实现；无需输入的图框字段（质量、工艺、修订、日期、页码空栏等）维持模板空白，不编造签名或日期。浮点输入转换为有限 Decimal，API 用十进制字符串传输，禁止 NaN/Inf 与布尔冒充数字；输出避免浮点尾差。文字保留语义与原文，不能默默截断。安全限制与溢出报错分开，不能用字符串长度代替实际字形边界检查。

建议工程初值：10 MiB/文件、500 条非空业务行、100 MiB 解压总量、2000 个 ZIP entries、单文字字段 256 Unicode 字符；B03/B10 实测后可调配置并在 UI 展示。这些是资源保护参数，不是已验证的业务极限。代码/文件名拒绝路径分隔符、控制字符、`..`、尾部点/空格、Windows 保留名称和跨平台非法字符；大小写折叠后的重名也须报错，不靠自动追加后缀修复。

## R03：受控模板

纵向 A4 210×297 mm；保留黄色图框、黑色轮廓/主要文字、字体风格、标题栏与固定技术要求。原 DWG 为 AC1032。模板实体、锚点和有效绘图区目前未原生测量，B02 必须从样件提取/测量后写入 `layout.json`；不得在实施中凭聊天截图猜坐标。

固定技术文字（除占位符外不能由 AI 修改标准或材料）：

1. 电阻值：R={resistance_ohm}Ω±{tolerance_ohm}Ω；
2. 单回路；
3. 康铜箔BMn40－1.5，GB/T6145-2010；
4. 聚酰亚胺薄膜HF，GB/T13542.6-2006；
5. 导线 Q/YC97A-2011，导线长度均为300mm；
6. 导热线条的走向按工艺最佳方案，但导线的引出方向按图所示；
7. 加热片尺寸以图中标注为准；
8. 数量：{quantity_text}。

原包没有 PC3/CTB/STB 打印配置；HZDX.SHX 是已知字体，不证明它是唯一依赖或允许再分发。B02 要记录字体来源、文件 hash、渲染/打包权限以及必要替代的人工批准。缺字、字体无声明替换、文字越界必须失败，不悄悄变方框或位图文字。可编辑 CAD 保留 TEXT/MTEXT、原生 DIMENSION 等实体；PDF 可以嵌字或矢量轮廓，但不能拿整页图片冒充 CAD。

## R04：几何、比例与排列

- 宽沿水平，长沿竖直，直角矩形、无孔无圆角；两条引线居中，短边向上、长边向左，正方形始终向上。
- 令S=min(宽,长)/比例分母，纸面mm：双线间距=min(12,max(2,0.25S),0.60S)；内伸=min(10,max(2,0.20S),0.35S)；外伸=min(12,max(3,0.25S))。小尺寸短边保护优先于名义下限；与实际尺寸线/箭头/字形间隙须≥0.25mm，否则拒绝并要求调整比例。示意不按真实300mm绘制。
- 几何 model space 按毫米 1:1；尺度改变不能改变真实轮廓尺寸。B02 验证本方案：每行一个横向 tile，纸框/字高/标注样式按分母 n 放大，layout viewport 1/n；PDF 按相同 tile 与 1/n 变换裁切。100×300 仍是 100×300 实体、标 100/300。原模板是纸面坐标 1:1，克隆时变换；不改原模板。
- 汇总 DXF 一个 modelspace 横向排列，tile 间保留至少 10 mm 纸面间隙；每个 heater 有按行序命名的 A4 layout。DIMLFAC=1、DIMSCALE=n，无伪造尺寸文字覆盖。若渲染器不能可靠处理该组合，B02 先解决或提出变更并确认，不拖到最终验收。
- 输入比例可放下就保持。超框时从版本化建议序列 `[1,2,5,10,20,50,100]` 中选择满足完整包围盒的最小分母；没有可行比例则报错。不自动旋转、换纸、改尺寸或无限缩字。
- 包围盒须包含尺寸箭头、文字、引线和固定模板禁入区；允许调整标注侧别，禁止相交/越框。纯字体/标题栏溢出不能靠缩小加热器解决，提示修改 Excel 或处理模板。
- 几何回读误差建议 ≤1e-6 mm；纸面数值映射误差 ≤0.1 mm；A4 页尺寸误差 ≤0.2 mm。这是软件一致性验收阈值，**不是加工公差**。B02 记录实际测量方法，不凭视觉判定 1e-6 mm。

## R05：确认、错误与完整性

导入后先整批校验。有错误或未确认比例时不出图。用户选择修正重传，或逐项勾选并明确确认跳过错误行；页面展示原因、原条数、跳过条数、最终预计页数。合法行不得因同一批有错误而悄悄先交付。

冻结后预期集合为“原顺序所有记录－明确确认跳过记录”。首次生成中任一行失败，即停止后续行和正式发布；已有中间产物保留诊断。可重试暂时失败，或新确认跳过该行后建立新修订再生成。旧确认不覆盖新错误、新输入、新模板或新比例。表级损坏、缺表头、系统缺字体/模板/转换器、磁盘故障等不可通过跳过全部行绕开。零有效行不能生成空正式包。

原输入、每次修订、运行 ID 与最终产物不覆盖。取消、重启及迟到 worker 结果不能把旧任务写进新修订。生成成功后仍是 `pending` 人工复核；人工记录绑定精确产物 hash，换图后审核失效。

## R06：交付

包名默认“加热器图纸”，允许安全自定义；单页 `pdf/<code>.pdf`；汇总 `<name>.dxf`、`<name>.pdf`；按输入行顺序合并。原始 Excel 字节不变。`actual.xlsx` 的 Sheet1 仅含真正交付的行及最终比例，另页 `变更记录` 记录原行号、原值、确认值和跳过原因；`original.xlsx` 保留完整输入。必须有 `row-report.json` 和 `manifest.json`。

manifest 逐项列相对文件名、MIME、字节数、SHA-256、row_id/page 索引；集合必须等于冻结预期集合、无重名无多页无漏页。若 DWG 启用，作为同一集合的额外交付项参与完整性检查；DXF/PDF 基线模式不宣称有 DWG。manifest 不计算自己的 hash；外层任务记录绑定 manifest 与 zip 的 hash，避免自引用。

## R07：工程关系

AutoCAD 是 CAD 检查工具，Acrobat DC 是 PDF 阅读/复核工具，不是只支持 DWG 的程序。Linux 服务无需安装 Windows AutoCAD；但应在接收方 AutoCAD 2018 或明确批准的目标 CAD 完成可编辑 DXF 验收。替代 CAD 的结果不能冒充 AutoCAD 验收。DWG 需额外证据和授权，见 B02。
