## 实现结果

- 新增确定性 `plan_pages(revision, template) -> PagePlan(pages, issues, proposals, diagnostics)`。输入 revision 会重新校验内容 hash，模板会从受控目录重新加载并核对 template/version/font hash；函数不修改 revision。
- 真实矩形、双引线和原生标注定义始终使用 modelspace mm。比例只改变纸面映射、模板/DIMSCALE 和 viewport；`DIMLFAC=1`。短边向上、长边向左、正方形向上，沿用 `short-edge-paper-v1`，未改 300 mm 技术文字。
- 完整预检复用 B02 writer/readback：临时诊断 DXF 检查轮廓、引线、原生 DIMENSION、完整箭头/缓存、文字字形 bbox、框线/禁入区、字体覆盖和 0.25 mm 引线间隙，临时文件不注册为 Artifact。通过结果写入 `DrawingPage.checks`。
- 输入比例可行时保持；超框按 `[1,2,5,10,20,50,100]` 提出最小可行 `ScaleProposal`。有 proposal、任一 error 或空/不完整 pages 时 `export_planned_dxf` 拒绝正式 DXF；warning 完整保留但不阻断，不替用户接受比例。
- 汇总 DXF 按输入顺序横向 tile，每行独立 A4 layout。不同相邻比例的 modelspace 间隙按两侧换算均不少于 10 mm 纸面；page mapping 明确记录 `page_index/row_id/code/layout_name/scale`。
- `draw_case.py` 同时消费 `ParsedWorkbook.issues` 和 `ValidationResult.issues`，任一 error、source/normalized 行覆盖不完整或零有效行均不绘图。真实三行保持 `1:1 / 1:1 / 1:2`。
- 坐标 `Point/Bounds` 新增严格 ASCII 有符号十进制，以便在 issue/proposal 中表达越过纸面原点的失败候选；正尺寸及比例约束未放宽，Schema 已同步。
- runner 依赖验证从生产 registry 与 hash 校验后的日志重算 command `status`：required 负例可 `status=passed/exit=1`，optional 能力可 `status=blocked/exit=2`；矛盾自报状态、required blocked/failed、非法 exit、缺失或 hash 漂移日志均拒绝。

## 后续 Batch 接口与约束

- B05 必须消费本批 `DrawingPage` 与同一 DXF/layout mapping，不得从 Excel 重算第二套几何；正式 PDF 集合按 `expected_row_ids` 与 page 顺序核对。
- B06 对 `issues/proposals` 进入等待用户状态；只有用户接受 proposal 后创建包含新 `final_scales` 的 Revision，再重新 `plan_pages`。不得对本批 proposal 原地改 revision 或绕过 `exportable` gate。
- `DrawingPage.geometry_mm` 是真实尺寸；`placement.model_origin_mm/tile_bounds_mm` 是汇总 modelspace 定位；`paper_bounds_mm` 与 layout viewport 是纸面解释。消费者不得把 1:2 page 的 100×300 改成 50×150 实体。
- 正式导出前仍需同时保留 parse/validation/planning 全部 error 语义；非空规范 rows 不代表整批有效。诊断输出不得注册成 Artifact。
