## 本轮样件修正

- 原生 MTEXT 原始格式保持不变，只替换字段占位内容；保留 `\pxqc;` 和 `{\H1.042x;...}`。
- MTEXT 有效签名同时绑定字高、字宽、颜色、段落对齐、流向和行距样式。
- 实际字形边界用于可见内容、单元格/纸张边界、原模板跨框基线及可编辑文字碰撞检查。
- H3、W3、C1 和 `flow_direction=3` 变体均能被拒绝；无害 H1/W1 默认值继续接受。
- PDF 字体缩放按用途拆分：HZ 临时替代为 0.8，原生 `HEATER_CJK`/Noto 尺寸文字保持 1.0。
- 六处原生尺寸文字的 PDF/native 宽高比为 `0.999997313` 至 `1.000001927`，最大边缘误差小于 `0.00001 mm`。
- 单行原生尺寸 MTEXT 使用锁定 fontTools 字体指标，Windows 与 Linux 得到一致字形框；普通多行 MTEXT 仍使用实际 MTEXT 展开路径。
