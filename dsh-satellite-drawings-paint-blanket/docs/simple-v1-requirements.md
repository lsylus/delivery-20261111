# 插件简化版需求确认

日期：2026-11-09。用途：记录本次已确认的产品范围，供后续在干净对话中集中修改现有源码。本次仅讨论并做只读核查，未修改远端源码。

## 1. 目标与开发方式

- 沿用现有主要流程，集中简化并完成一轮可演示、可使用的版本。
- 主要流程：导入 STEP → 在三维模型中选择包覆对象 → 选择平面安装面 → 选择方形罩或圆柱罩及放量 → 指定不包的小零件 → 预览包覆与开口 → 展开、调整搭接等参数 → 输出 DWG。
- 第一版优先立方体、圆柱体、立方体与圆柱体组合三个样例。复杂拟合和球形暂缓。
- 不沿用大量独立对话反复开发审查的方式，不把后续复杂算法纳入本轮。

## 2. 整星导入与三维选择

- 每次由用户明确选定一个包覆对象；该对象可以由用户选择的多个部件组成。
- 直接在三维模型上点击选择包覆对象、不包覆的小零件和安装面。
- 本轮不做部件编号和部件列表界面。这是用户最后一次修订，覆盖此前关于列表、编号及列表联动的建议。
- 后端可保留可靠选择所需的装配实例身份与引用，不要求前端展示编号。
- 首版按 STEP 中真实独立部件或独立实体选择小零件；不要求把单一实体上的凸台自动拆分成部件。
- 用户决定处理整星中的哪一部分；本次被选中的包覆范围应完整包住，露出部分须明确指定。

## 3. 安装面与坐标

- 安装面只允许平面。圆柱侧面可作为包覆外形，但不作为安装面。
- 安装平面确定底部位置，包覆方向朝选定对象所在一侧。
- 平面内方向从模型方向自动给定，显示方向预览。
- 主界面保留必要的反向、旋转；原点和坐标数值等放入高级设置。
- 方形罩和圆柱罩默认安装底面敞开，包覆侧面与顶部。

## 4. 常规外形与放量

- 方形罩、圆柱罩作为首选，用户预览并选择。小台阶、倒圆等只要在罩内，不逐一跟随。
- 接受复杂对象使用留有更多空隙的常规罩形。可以只处理用户选定的部分，其余部分另行处理。
- 本轮完成常规外形完整流程；更贴合的自动细化算法列入后续。
- 默认尺寸放量系数为可调整的 1.05：方形罩长宽高、圆柱罩直径和高度增加 5%，安装底面位置固定。
- 搭接宽度单独计算，不计入尺寸放量的 5%；显示放量后的实际尺寸。
- 原包络体积比 1.2 改为可调整的参考值，超过时提示，允许继续使用常规外形方案。
- 尺寸放量 1.05 与体积比 1.2 是不同指标，不可混用。

## 5. 不包覆的小零件与开口

- 用户在三维模型中选择小零件“不包覆、让它露出”，软件据此生成开口，不要求先手动画孔。
- 不包的小零件不再撑大罩壳，在其穿出罩壳的位置留孔；预览中保留该小零件以便检查。
- 示例：箱体与顶部独立小圆柱，箱体包覆、小圆柱不包；罩壳按箱体生成，并在顶部开孔使圆柱露出。
- 开口先用可容纳小零件的矩形或圆形，允许调整尺寸。
- 首轮开口支持方形罩的平面、圆柱罩的顶部平面。
- 圆柱侧面开口、跨多个罩面的开口遇到时明确提示本轮范围限制。
- 一体实体上的局部特征自动识别、自动开口放到后续。
- 收起逐面添加包覆面、复杂外形策略等入口，以本节直接选择小零件的流程为主。

## 6. 裁片上限与计算停止

- 裁片指最终需要独立裁切、制作的二维片料，不等同于三维几何面、制造面或渲染三角形。
- 按一个对象、每层分别统计；同层形状相同的两片仍算两片。
- 默认上限 10 片，用户可修改；生成过程遵守当前上限。
- 多层总制作数量另行显示。例如三层各四片：每层按四片检查，总数量十二片。
- 达到上限停止继续细化，保留可查看的当前方案，明确显示上限已到和未满足的要求，不自动突破限制。
- 本轮首先落实数量检查和明确提示，不借此扩展一套复杂优化算法。
- 内部另设必要的几何复杂度、计算量限制；裁片少不等于轮廓或折线必然简单。
- 体积比超过参考值可以提示并由用户采用；不能与超过裁片上限混为同一种结果。

## 7. 本轮验收

- 三个简单样例验证完整流程：选择对象与平面、常规罩形、组合件中小零件露出、开口预览、二维展开、搭接调整、DWG 输出。
- 组合样例用独立部件装配，至少验证箱体顶部的小圆柱露出。
- 真实整星 STEP 必须验证导入，以及直接在三维模型中选择包覆对象和安装面。取消此前的编号、列表及列表联动验收项。
- 不把整星所有部件全部完成包覆出图作为本轮要求。
- 安装后提供用户可直接打开界面的侧边栏或菜单入口。
- 在目标 CAD 软件中实际验证 DWG 的打开、文字显示和可编辑性；生成了文件不代表已通过该项验收。
- 验证裁片上限、每层计数、参考体积比超限提示及明确的范围限制提示。
